## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Sandeep-Kumar-930/Touch_aim.git
```

### 2. Navigate to the project

```bash
cd Touch_aim
```

### 3. Create a virtual environment

```bash
python -m venv .venv
```

### 4. Activate the environment

**Windows PowerShell:**

```powershell
.\.venv\Scripts\Activate.ps1
```

### 5. Install dependencies

If the project contains a `pyproject.toml` file, you can use:

```bash
uv sync
```

Otherwise, install the required packages according to the individual project's instructions.

---

## 🔐 Environment Variables

Some projects require API keys or other environment variables.

Create a `.env` file in the relevant project directory:

```env
GROQ_API_KEY=your_api_key_here
```

**Important:** Never commit your actual API keys, passwords, or sensitive credentials to GitHub.
